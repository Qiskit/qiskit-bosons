# cre

### cre(mode)

Constructs a creation action on the bosonic mode at `mode`.

* **Parameters:**
  **mode** ([*int*](https://docs.python.org/3/builtins/functions.html#int)) – the bosonic mode on which to act.
* **Returns:**
  A creation [`BosonAction`](qiskit_bosons.operators.boson_action.BosonAction.html.md#qiskit_bosons.operators.boson_action.BosonAction) on `mode`.
* **Return type:**
  [tuple](https://docs.python.org/3/builtins/stdtypes.html#tuple)[[bool](https://docs.python.org/3/builtins/functions.html#bool), [int](https://docs.python.org/3/builtins/functions.html#int)]
